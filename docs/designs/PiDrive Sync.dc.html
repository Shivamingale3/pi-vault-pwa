SYNC RULES
Sync never blocks entry to the vault
Both failures offer Continue offline first
Offline is a pill, never a screen
Progress is always named, never a bare spinner
A stopped sync overwrites nothing
Sixty seconds, then it gives up
Screen 1 shows three named stages with counts, so a slow sync reads as working rather than stuck. Screen 6 borrows the dark treatment from the existing signed-in success state and leaves on its own.
Media stays server-only, so the tab greys out while offline. Passwords and notes carry a dot when they hold unsynced edits.
